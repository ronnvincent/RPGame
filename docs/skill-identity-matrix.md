# Character Skill Identity Matrix

The six slots keep a consistent learning pattern: basic attack, core technique,
control/utility, build-defining skill, mobility or power skill, then ultimate.
The execution and presentation listed here are acceptance criteria, not flavor
text. If the game cannot perform an effect, the description must not promise it.

## Warrior — steel, crimson, dust, weight

| Skill | Gameplay identity | Presentation identity |
| --- | --- | --- |
| Basic Slash | Three-step grounded greatsword combo; aerial downward cut | Alternating horizontal/upward/heavy steel arcs |
| Whirlwind | Three evenly split radial hits while the warrior can drift | Circular steel trail with dust on every hit |
| Shield Bash | Short cone, strong stagger, brief enemy stun | Shield-shaped shock ring and hard spark |
| War Cry | Party ATK increase plus smaller DEF increase for eight seconds | Crimson rally ring, rising embers, roar pulse |
| Blade Dash | Armored forward dash that cleaves once and grants short i-frames | Long red-white blade streak and afterimage |
| Earth Shatter | Leap, telegraphed landing, fissure AoE, heavy knock-up | Brown-gold cracks, rock burst, impact-timed shake |

## Cross-cutting validation

- All damage promised as multiple hits is split across those hits; it is not
  multiplied again for every tick.
- Projectile gameplay and projectile VFX share travel time and impact position.
- Ultimate damage and heavy camera feedback occur on the cinematic impact beat.
- Delayed casts are cancelled when changing scenes, returning to town, dying,
  disconnecting, or replacing the active run.
- Remote clients receive the same presentation event sequence as the caster,
  while the authoritative simulation produces health/status results once.
- Every status has a gameplay timer, a visible marker, and an expiration event.
- Each class has a distinct palette and silhouette even with screen flash off or
  reduced-motion enabled.
